Why is this a Hamiltonian cycle?

The algorithm begins at A, extends the path using only connected and unvisited vertices, and accepts a solution only if all vertices have been visited AND the final vertex connects back to A. The final return to A does not count as an extra visit to a new vertex.

1. Hamiltonian path vs cycle

Path: visits each vertex exactly once. Cycle: does the same and includes the closing edge back to its start. A path alone is not sufficient.

2. What is backtracking?

When a candidate leads to a dead end, remove it from the current path, return to the previous vertex, and try another valid choice.

3. Algorithm complexity

Time: O(n!) in the worst case. Auxiliary space: O(n) for the current path, visited information, and recursion stack. Recording the animation history uses extra space.
